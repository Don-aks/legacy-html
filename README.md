# Legacy HTML/CSS/JS Portfolio

A curated collection of legacy web projects built with vanilla HTML, CSS, and JavaScript. Developed using jQuery and classic libraries, these demos are optimized for older environments — including Internet Explorer 11 — without compromising on polished layouts, fluid animations, or responsive design.

## Projects

- [Cyber Security Firm Ovodov](https://legacy-html.vercel.app/cyber/)
- [Hair Salon Gloss](https://legacy-html.vercel.app/gloss/)
- [Beauty Clinic Medi](https://legacy-html.vercel.app/medi/)
- [Natural Products Shop Wild Souls](https://legacy-html.vercel.app/souls/)

## About this repo

This repository contains portfolio-style pet projects that highlight:

- browser compatibility with Internet Explorer 11
- handcrafted HTML/CSS structure
- responsive design for desktop and mobile
- vanilla JavaScript interactivity
